Effet : le menu s'ouvre ou se ferme (le CSS définit ce que .is-open affiche)
Décodage ligne par ligne :

document.querySelector('.menu-btn') → trouve le bouton dans la page
addEventListener('click', () => { ... }) → "quand on clique, exécute ce code"
classList.toggle('is-open') → ajoute la classe si absente, la retire si présente

RAPPORT 

1. le modèle évènement -> état -> rendu permet de comprendre ce qu'il ce passe lorsqu'on effectue une action/intéraction avec un élément de la page. par exemple : je clique sur un bouton, il active le déploiement d'un onglet et l'ongle est ouvert et je peux intéragir avec.

2. classList.toggle : toggle sert à indiquer au navigateur: "Si c'est là, enlève-le ; si c'est pas là, mets-le." et inversement
